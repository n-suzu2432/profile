# ポートフォリオサイト — 要件定義

## プロジェクト概要

薬剤師・デザイン・マーケティングのスキルを持つ個人のプロフィールサイト。
自己紹介・経歴・スキルを 1 ページで完結させる静的サイト。

**目的**
- SNS 発信・自己ブランディングの起点となるプロフィールページを持つ
- 薬剤師 × デザイン × マーケティング × AI という複合スキルを可視化する

---

## 技術スタック

| 項目 | 採用技術 |
|------|---------|
| マークアップ | HTML5 |
| スタイリング | CSS3（`<style>` タグにインライン記述・外部依存なし） |
| JavaScript | 不使用（静的ページ） |
| フレームワーク | なし（単一 `index.html` で完結） |

> Next.js + Tailwind CSS 版のコンポーネント（`components/*.tsx`）も同ディレクトリに残存しているが、
> メインの成果物は `index.html`。

---

## ファイル構成

```
portfolio/
├── index.html        # ★ メイン成果物。これをブラウザで開く
```

## セクション要件

### 0. ナビゲーション

- **仕様**: 固定ヘッダー。各セクションへのアンカーリンク
- **リンク**: TOP / 経歴 / スキル / 自己紹介
- **デザイン**: 半透明ティール背景 + `backdrop-filter: blur`

### 1. Hero（ファーストビュー）

- **目的**: 第一印象で「誰なのか」を伝える
- **表示内容**
  - サブタイトル: `Pharmacist × Designer × Marketer`
  - キャッチコピー: 「薬剤師として12年。今、新しい挑戦へ。」
  - 自己紹介文（岐阜在住・スキルの掛け合わせ）
  - タグ: 薬剤師 / デザイン / マーケティング / AI学習中 / FP3級 / アロマ
  - 座右の銘: 「ケ・セラ・セラ」
- **デザイン**: ティールのグラデーション背景・白文字・全画面（`min-height: 100vh`）

### 2. Career（経歴）

- **目的**: 信頼性・経験の厚みを伝える
- **表示内容（時系列）**

  | 期間 | 内容 | 種別 |
  |------|------|------|
  | 2013年3月 | 近畿大学薬学部 卒業・薬剤師国家試験合格 | 学歴（青） |
  | 2013年4月〜2021年3月 | 国立病院機構 三重中央医療センター（8年） | 職歴（ティール） |
  | 2021年4月〜2024年3月 | 国立病院機構 長良医療センター（3年） | 職歴（ティール） |
  | 2024年4月〜10月 | 職業訓練校（デザイン・マーケティング習得） | 学習（アンバー） |
  | 2024年11月〜現在 | ふかせ調剤薬局（現職） | 職歴（ティール） |

- **デザイン**: 縦タイムライン。PC では左右交互レイアウト。学歴/職歴/学習をドットの色で区別

### 3. Skills（スキル・資格）

- **目的**: 保有スキルと資格を整理して見せる
- **表示内容**
  - 資格カード: 薬剤師免許 / FP技能士3級 / アロマテラピーアドバイザー
  - スキルカード: 医療・薬学 / デザイン・マーケティング / 現在学習中
- **デザイン**: CSS Grid 3カラム。カードの上ボーダー色でカテゴリを区別

### 4. About（自己紹介）

- **目的**: 人柄・価値観を伝えてファン化を促す
- **表示内容**
  - 基本情報（年齢・出身・居住地・職業・家族・性格）
  - 趣味（温泉・サウナ・神社巡り・アイスコーヒー・海外旅行）
  - 価値観・座右の銘・信念
  - 締めのメッセージ: 「人生は自分次第で変わっていく。」
- **デザイン**: 2カラムレイアウト。締めはティール背景の引用ブロック

## デザイン原則

- **メインカラー**: Teal（`#0f766e` / `#14b8a6`）— 信頼感・誠実さ
- **アクセントカラー**: Amber（`#f59e0b`）— 活力・挑戦
- **補助カラー**: Blue（`#3b82f6`）— 学習・成長
- **ベース**: `#f9fafb`（背景） / `#fff`（カード） / `#1f2937`（本文）
- **CSS変数**: `:root` に色を集約（`--teal-500` 等）
- **フォント**: システムフォント（`-apple-system, BlinkMacSystemFont, "Noto Sans JP"`）
- **レスポンシブ**: モバイルファースト。`@media (min-width: 768px)` で 2 カラム切り替え
- **外部依存なし**: CDN・npm パッケージ不要。ファイルを開くだけで動作する
